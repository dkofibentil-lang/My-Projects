Working with Definition/Description Lists

HTML
HTML is an Acronym that means Hypertext Markup Language. It is the Basic Language of the World Wide Web. It is used to Create the Structure of the Web. It is Made up of tags. A tag is a special word placed in an Angular brace. Tags that have special meaning are the Semantic tags. HTML is not a Programming Language because it does not have basic programming construct like Conditional Statements and Loops.
CSS
CSS means Cascading Style Sheet. It is used in style and making Web Pages and Web Applications Beautiful and more Presentabele. It Depends on the Structure of HTML to Style. It is made up of Selectors, Properties and Values. Without CSS or Web Pages and Web Applications will be very BORING......
